Assay gives every open-weight AI response a receipt. It names the model and the host, the host signs it and anchors it on Monad, and you can co-sign it with your passkey.

        
It proves who served which bytes and what they claimed. Not which weights ran.

What a receipt proves, and what it doesn't.

      

      

        

          
A receipt proves

          
    
            
  • Which host served these exact bytes.
    • 
            
  • Which model the host claimed, signed so it can't be denied later.
    • 
            
  • That it sits in a batch the host anchored on Monad.
    • 
            
  • Who asked, if you co-signed with your passkey.
    • 
          

        

        

          
It doesn't prove

          
    
            
  • Which weights actually ran. A host can still sign a claim it didn't keep.
    • 
          

          
That gap is why hosts get graded against the lab's own endpoint, with the raw logs published. Hosts that sign from inside a TEE, with a model hash in the attestation, are next on the roadmap.

          Read the threat model
        

      

      

      
    
        
  1. Level 0, live on mainnetSigned and anchored
    The host signed what it served and the batch is on Monad.

  2. Level 1, live on mainnetHost graded
    Open verifiers test the host against the lab's own endpoint.
    3. 
        
  3. Level 2, roadmapRe-executable
    A deterministic runtime lets anyone re-run a revealed request.
    4. 
        
  4. Level 3, roadmapTEE attested
    The host signs from an enclave whose attestation names the model.

Wrap fetch. Keep the receipt.

        
The SDK sends the salt and your co-signer key with each request, parses the receipt from the response and checks that the output commit matches what you received.

        
$ npm install assay-receipts

        
From an empty folder, it verifies the first mainnet receipt in about 350 ms.

import { wrap } from "assay-receipts";

const ask = wrap(fetch, { cosigner }); // your passkey's key hash

const { json, receipt, salt } = await ask(
  `${HOST}/v1/chat/completions`,
  { method: "POST", body: JSON.stringify({ model, messages }) },
);

// receipt.hash lands in a Merkle batch on Monad.
// Keep salt: it opens the commits later.


import { verifyReceipt } from "assay-receipts";

const hash = process.argv[2];
// The receipt, its batch proof and root, from the host that served it.
const { body, jws, proof, root } = await fetch(`${HOST}/v1/receipts/${hash}`).then((r) => r.json());
const jwks = await fetch(`${HOST}/.well-known/jwks.json`).then((r) => r.json());

// client: any viem PublicClient on Monad. anchor: ReceiptAnchor on mainnet.
const anchor = "0x049A73755cA3508ef3Daa4752A3406f6e00CfB13";
const { checks } = await verifyReceipt({ body, jws, jwks, proof, root, onchain: { client, anchor } });
for (const [name, r] of Object.entries(checks)) console.log(name.padEnd(13), r);
